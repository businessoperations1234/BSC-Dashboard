Setup guide

How the auto-refresh works

When you (or anyone you share this file with) click Refresh, the dashboard signs into Microsoft, calls Microsoft Graph to download the latest BSC Dashboard_Excel.xlsx from SharePoint, and re-renders. Anyone with SharePoint access to the file can refresh — they don't need anything else installed.

One-time setup: Azure AD App Registration

Your tenant needs a tiny app registration so the dashboard can authenticate. Do this once, then paste the Client ID into Settings.
  1. Go to Azure Portal → Microsoft Entra ID → App registrations → New registration.
  2. Name it something like "BSC Dashboard Reader".
  3. Account types: Accounts in this organizational directory only.
  4. Redirect URI: choose Single-page application (SPA) and add the URL where this file will be hosted (or http://localhost if running locally).
  5. After creation, on the Overview page, copy the Application (client) ID.
  6. Under API permissions, add: Files.Read.All and Sites.Read.All (delegated). Grant admin consent.
  7. Open this dashboard's Settings and paste the Client ID. Save.
  8. Click Sign in to SharePoint → authenticate → Refresh.

If you can't register an Azure app

Use the Upload button in the top right to load a copy of the xlsx manually. All filters, charts and the Claude chatbox work the same way — you just won't get live auto-refresh.

Claude analysis chatbox

After data loads, scroll to the bottom of the dashboard. Paste your Anthropic API key in Settings, then ask any question about the data ("Which perspectives are underperforming?", "Summarize Q1 status for the Customer perspective", etc.). The chatbox sends the currently-filtered rows to Claude so analysis always reflects your live view.
